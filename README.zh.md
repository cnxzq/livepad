# livepad

[English](./README.md) | [中文](./README.zh.md)

实时协作便签 + 文件共享 — 零依赖，仅用 Node.js 内置模块。

- 📝 满屏 textarea，多客户端实时同步
- 📎 文件附件上传/下载/删除，所有人可见
- 🔒 启动默认清除临时文件，防止隐私泄漏

## 使用

```bash
npx livepad              # 默认 3000 端口，自动清除历史文件
npx livepad 8080         # 指定端口
npx livepad --keep       # 保留上次会话的文件
```

打开浏览器访问 `http://localhost:3000`，多个标签页/设备访问同一地址即可实时协作。

### Docker

```bash
# 快速启动
docker run -p 3000:3000 zqzyz/livepad

# 自定义端口
docker run -p 8080:8080 -e PORT=8080 zqzyz/livepad

# 持久化上传的文件
docker run -p 3000:3000 -v livepad-data:/tmp/.livepad zqzyz/livepad

# 保留上次会话的文件（不清除）
docker run -p 3000:3000 -v livepad-data:/tmp/.livepad zqzyz/livepad --keep
```

或使用 docker compose：

```bash
docker compose up -d
```

## 解决了什么问题

- **零配置** — 无需安装、无需注册。一条 `npx livepad` 即刻启动
- **数据不出设备** — 零云服务依赖，数据始终留在你的机器上
- **零依赖** — 无供应链风险，代码可轻松审计（只有一个小 JS 文件）
- **跨设备剪贴板** — 电脑打字，手机即时可见（同一局域网）
- **快速传文件** — 不用 U 盘、不用发邮件给自己，设备间直接传

## 适用场景

- 在个人设备之间传文字或代码片段
- 会议中临时协作记笔记
- 局域网内电脑间快速传文件
- 替代 pastebin，不经过第三方服务
- 结对编程时的临时共享便签
- 无互联网或受限网络环境下的局域网协作

## 不适用场景

- **生产级文档协作** — 请用 Google Docs、Notion 等专业工具
- **长期保存笔记** — 默认启动清除临时文件（`--keep` 需谨慎使用）
- **大文件传输 (>100MB)** — 不支持分块上传和断点续传
- **需要登录/权限管理** — 无内置认证和用户管理
- **需要编辑历史/版本控制** — 仅支持浏览器级撤销
- **敏感数据加密存储** — 无加密功能
- **外网访问** — 无内置 HTTPS 或隧道穿透

## 功能

| 功能 | 操作 |
|------|------|
| 实时协作编辑 | 左侧 textarea 直接输入，停止 500ms 后同步 |
| 上传附件 | 点击"上传"按钮 或 拖拽文件到页面 |
| 下载附件 | 点击附件列表中的文件名 |
| 删除附件 | 点击文件右侧 ✕ |
| 清空附件 | 点击"清空"按钮 |

所有客户端看到的附件列表实时同步。

## 原理

- **SSE** — 服务端推送文本和文件列表更新
- **HTTP POST + multipart** — 纯手工 multipart 解析，零依赖
- 文件存储在系统临时目录 `.livepad/`（默认启动清除）
